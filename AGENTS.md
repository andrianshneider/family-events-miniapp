# Meetmallow: правила работы с ветками

- Основная и рабочая ветка проекта — `main`. Начинайте дальнейшие изменения с актуальной `main` и сохраняйте результаты в неё.
- `infrastructure-foundation` больше не используется для разработки, тестирования новых изменений или новых выпусков. Она остаётся историей этапа проверки архитектуры.
- Не возвращайте workflow на `infrastructure-foundation` без прямого указания пользователя.
- Для новых Preview/staging и Production сборок используйте соответствующий коммит `main`, сохраняя разделение конфигурации окружений. Перенос кода в GitHub сам по себе не является публикацией в Production.
- Соблюдайте унаследованные инструкции проекта, в том числе запрет изменения `sources/` и запрет вывода или коммита секретов.
