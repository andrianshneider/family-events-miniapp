# Family Events

Кликабельный прототип Telegram Mini App: профиль пользователя Telegram и заглушка раздела «Списки желаний». В обычном браузере доступен демо-режим.

Приложение представляет собой статический сайт: `index.html` и `manifest.json`. Для публикации на Vercel достаточно подключить этот репозиторий без команды сборки.

Бот: [@FamilyEventsMiniAppBot](https://t.me/FamilyEventsMiniAppBot?startapp).

Текущая версия отображает данные пользователя из Telegram WebApp на клиенте. Она не выполняет серверную проверку подписи `initData` и не должна использоваться как защищённая авторизация для сохранения личных данных.
