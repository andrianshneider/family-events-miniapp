# Meetmallow

The user approved `08-orange-arms.png` on 12 November 2026 (project mirror `icon-concepts/SELECTION.md`). `meetmallow-approved.png` is an unchanged copy of that source: orange background, two embracing white marshmallows of different sizes.

Generate application assets with `node --import tsx scripts/generate-brand-icons.ts`. The script resizes the approved art for 180/192/512 px Apple/PWA/favicon use and provides a full-bleed orange maskable icon with its content inside the 80% safe circle. Original icon paths remain compatible with existing installations. Manifest ID, scope and start URL stay `/` to preserve installed app identity. No new icon concept is generated.

Current UI, metadata, install instructions, offline page and invitation OG previews use Meetmallow. Existing infrastructure IDs, bot username, repository name, session/storage keys and historical specification titles are deliberately preserved.
