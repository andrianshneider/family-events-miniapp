# Family Events

Существующий статический прототип Telegram Mini App. Главный экран — «Мои события», реализованный по пользовательскому референсу `assets/home-reference.png`. Исходный референс сохранён без изменений; фотографии отображаются через SVG-области кадрирования.

## Запуск

Откройте папку через любой статический HTTP-сервер, например `python3 -m http.server 8765`, затем http://localhost:8765. В браузере нажмите «Посмотреть прототип». В Telegram сохранён автоматический переход по наличию профиля из WebApp SDK.

Файлы для публикации: `index.html`, `app.js`, `styles.css`, `manifest.json`, папка `assets`. Сборка не требуется. Это обновление существующей Vercel-копии; прежняя папка `family-events-site` относится к старому хостингу и не изменена.

## Сценарии

- Предстоящие события, прошедшие и черновики с реальными счётчиками по демо-данным.
- Ближайшее событие, фотографии, участники, дата и место.
- Поиск по названию и месту, пустой результат.
- Детали события, участники, уведомления и переход к вишлистам.
- Создание события и сохранение/редактирование черновика; данные хранятся только в localStorage этого браузера.
- Нижняя навигация: события, календарь-повестка, создание, вишлисты, профиль.
- Сохранённые вход/выход из демо, Telegram-профиль и цвета темы.
- Создание вишлиста: название до 60 символов, описание до 300, выбор обложки и режима доступа; переход из раздела «Вишлисты» и маршрута `#wishlist-new`.
- Список вишлистов, просмотр созданного списка и добавление желаний. Данные сохраняются локально в `fe-wishlists-v1`.
- Доступ по ссылке сохраняется как настройка; публикация, синхронизация и серверная проверка доступа не подключены.
- Чат остаётся явно обозначенной заглушкой.

Даты примеров перенесены на 2026 год; категории и число дней до события вычисляются по текущей локальной дате. Демонстрационные числа из референса заменены фактическими счётчиками (изначально 5 предстоящих, 1 прошедшее, 2 черновика).

## Проверка

Проверено в браузере: вход/выход, три вкладки, поиск и отсутствие результатов, детали, чат-заглушка, участники, подарки → вишлисты, календарь, профиль, уведомления, создание и сохранение события после перезагрузки. Проверена мобильная раскладка. Бэкенд и реальная отправка приглашений не подключены.

Бот: https://t.me/FamilyEventsMiniAppBot?startapp

Текущая версия читает профиль Telegram на клиенте. Серверная проверка подписи initData и защищённое хранение данных ещё не реализованы.

## Экран создания вишлиста

Откройте «Вишлисты» → «Создать вишлист». Реализован экран из согласованного макета Figma с локальными SVG и шрифтом Inter. Пустое или состоящее из пробелов название не позволяет создать список. Незавершённая форма сохраняется при переходах внутри сеанса. При недоступном localStorage данные остаются в памяти, а приложение сообщает об этом.

Проверено в Chrome: создание, выбор доступа и обложки, возврат к форме, добавление желания, сохранение после перезагрузки, переход обратно к событиям, безопасное отображение текста и недоступное хранилище. Проверены ширины 320, 390 и 720 px. Серверный общий доступ и публикация на Vercel не входят в это изменение.
